Queries fetching game modes/maps for a roster do not join against 
the current game template → return ALL modes ever associated with 
the roster regardless of current template.

Hypothesis B — Template change not cleaning up:
When a roster's game template is changed, old game mode / map / stat field 
records from the previous template are never deleted → they accumulate.

Hypothesis C — Duplicate creation:
Something creates duplicate game mode/map entries (e.g., an init or 
seed function running more than once on the same roster).

Hypothesis D — Cross-roster leakage:
A query is missing a rosterId filter entirely → pulling modes/maps 
from other rosters into this one's view.

Identify WHICH hypothesis is correct (may be more than one).
